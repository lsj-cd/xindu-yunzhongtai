2推免硬性门槛（必须全部满足）

  • 身份：纳入国家普通本科招生计划的应届毕业生（专升本、二学位等不可参与）
  • 品德：无考试作弊、学术不端等处分记录
  • 学业：前三年专业核心课 无未修 / 补考 / 重修 / 取消资格记录
  • 排名：平均学分绩点排名 前40% + 综合素质测评排名 前40%（两个都要）
  • 英语：CET-4 ≥ 425 分（部分专业要求六级，六级另有加分）
  • 体检：符合研究生入学体检标准

4大一新生行动清单（现在就开始）

  • 大一·打地基 拼绩点是第一要务：电路、模拟/数字电子、高数、大物等基础课学分大、分差大，大一绩点排名基本决定能否进前40%
  • 尽早过四级 大一下或大二上过四级，冲六级（六级是加分项 + 部分院校接收条件）
  • 守住红线 考试不作弊、不挂科；一旦有补考/重修记录就可能被卡
  • 了解细则 关注学院官网"公告通知"栏的推免实施方案（每年9月发布）
  • 综合素质 认真参加综测：志愿服务、班级/社团活动都算

5大学四年时间轴

大一（现在）稳住绩点、过四级、了解细则、不踩红线
大二、大三保持绩点前20%更稳；参加电子设计竞赛 / 互联网+ / 挑战杯；跟老师进实验室，争取发论文、申请专利
大三暑假关注目标院校 夏令营，提前联系导师
大四9月报名 → 提交综合信息表+材料 → 综合能力答辩 → 学院公示 → 学校审定公示 → 体检 → 教育部"推免服务系统"填报志愿

  • 硕士推免生 生源奖学金 8000元/人，学费按 50% 收取
